# 输出增强

![:name](https://count.getloli.com/@astrbot_plugin_output_enhance?name=astrbot_plugin_output_enhance&theme=miku&padding=7&offset=0&align=top&scale=1&pixelated=1&darkmode=auto)

## AstrBot 插件：让Bot能够发送@、引用消息、合并转发消息、主动分段和转图片

## 使用前需要关闭的 AstrBot 设置

插件不会修改这些设置。对应能力开启时如果检测到冲突，会在日志里提醒。

| 使用的插件能力 | 需要关闭的 AstrBot 设置 |
| --- | --- |
| 分段回复 | `platform_settings.segmented_reply.enable` |
| 合并转发 | 将 `platform_settings.forward_threshold` 调到足够大，避免框架先折叠 |
| 文转图片 | `t2i` |
| 输出标记解析 | `provider_settings.streaming_response`（流式输出会跳过发送前装饰，标记无法解析） |
| 自动引用 | `platform_settings.reply_with_quote`（仅在不希望框架自动引用时关闭） |

分段默认只作用于模型回复。要把其他插件的消息也按同样规则切开，打开分段配置里的「分段插件消息」。

模型有时会用 `send_message_to_user` 发送当前会话的纯文本，从而绕过发送前处理。打开「接管纯文本工具发送」后，这种单独调用会改回普通回复，并关闭该轮流式输出。跨会话、定时任务、直播以及带图片、文件、语音、视频或 @ 的调用不会被接管。

## 输出标记

标记写在回复正文里，发送前会自动替换成真实消息组件。

| 标记 | 作用 |
| --- | --- |
| `{{AT:用户ID}}` | @ 指定用户，只接受数字 ID |
| `{{AT:all}}` | @全体成员，需同时允许 |
| `{{REPLY}}` | 引用触发这条回复的消息 |
| `{{SEG}}` | 在这里拆成两条消息 |
| `{{IMG}}` | 把整条回复渲染成图片 |

无法识别、未闭合，或对应功能未开启的标记会被移除。当前平台不支持 @、引用或合并转发时，相关处理会被跳过，其余内容照常发送。

## 默认注入提示词

开启`自动注入标记说明`后会将以下内容自动注入系统提示词末尾,且只会注入已开启的功能提示词

用来引导模型输出对应的标记

用户可以自行修改提示词，并填入`自定义注入内容`配置项或者`人格设定`中,效果一致

```text
你可以用下列标记控制这条回复的呈现方式。标记写在正文里，发送前会被替换，用户看不到标记本身。未知标记会被删除。
{{AT:数字ID}} 会 @ 对应用户。
{{AT:all}} 会 @全体成员。
{{REPLY}} 会引用用户这条消息。
{{SEG}} 是分段点，前后会分成两条消息发送。
{{IMG}} 会把整条回复渲染成图片。
```

## 主动工具

- `send_forward_message`：按模型给出的节点发送合并转发。节点内容可以按顺序混排文本、图片、QQ 表情和 @。图片支持网络地址；本地文件只能来自当前会话工作区或临时目录。
- `send_text_as_image`：把文本渲染成图片发送。只接收文本，不接收图片路径或 URL。

未在 `llm_tool_options` 勾选的工具不会注册。

## 文转图片

在插件配置里选择渲染器：

| 渲染器 | 特点 |
| --- | --- |
| Pillow | 本地渲染，轻量快速，可自定义正文字体、Emoji 字体和 JSON 模板。支持常见 Markdown，默认使用彩色 Emoji。自带 `templates/light.json` 和 `templates/dark.json`两套模板，支持自定义模板，留空默认使用亮色。不支持数学公式。 |
| AstrBot T2I | 使用 AstrBot 的文转图服务，可以渲染 Markdown 和数学公式。速度较慢，依赖渲染服务；模板样式在 AstrBot 自己的文转图配置里设置，不在本插件配置。 |

## 处理优先级

同一条回复按下面的顺序处理，命中后不再继续：

1. 错误拦截、消息拦截
2. 文转图片，包括 `{{IMG}}` 和字数阈值
3. 合并转发
4. 分段发送
5. 普通消息

文本清洗在这些判断之前执行。转图片和合并转发同时达到阈值时，优先转图片。处理失败会保留原文并记录日志。
